## Sobre

A DevHub desenvolve software sob demanda para pequenas e médias empresas que precisam de algo específico demais para as ferramentas de prateleira — seja porque o processo não cabe nelas, porque o custo por usuário não fecha, ou porque os dados precisam ficar em casa.

Trabalhamos do entendimento do problema à operação: arquitetura, implementação, publicação e manutenção.

## O que fazemos

| | |
|---|---|
| **⚙️ Sistemas de gestão** | Cadastros, ordens de serviço, contratos, agenda, relatórios e portais de cliente |
| **💬 Plataformas de atendimento** | Inbox compartilhado, integração oficial com a WhatsApp Cloud API da Meta, atribuição e histórico |
| **🤖 IA aplicada** | Copilotos que sugerem respostas para operadores humanos e bases de conhecimento com busca semântica (RAG) |
| **🔁 Automação de processos** | Trabalho manual repetitivo substituído por rotinas confiáveis |
| **🛒 Aplicações web e e-commerce** | Do front à API, com autenticação, controle de acesso e meio de pagamento |

## Como trabalhamos

> **Entender antes de propor.** Todo projeto começa com a leitura do que o cliente realmente precisa — e com as perguntas que mudam a estimativa. Proposta sem essa etapa é chute com aparência de orçamento.

> **Justificar cada escolha técnica.** Stack não se escolhe por moda: cada decisão vem com o motivo e com o que ela custa, inclusive em conta mensal de infraestrutura.

> **Entregar por blocos.** Escopo em fases com aceite formal, começando pela versão que já resolve o problema em produção.

> **Infraestrutura do cliente.** Sempre que faz sentido, o sistema roda em servidor do próprio cliente. Sem aprisionamento em plataforma.

> **Ressalvas por escrito.** Dependências externas, limites de escopo e aditivos ficam no contrato — não na conversa.

## Engenharia

Um sistema que o cliente vai operar por anos precisa sustentar mudança:

- **Controle de acesso por papel**, com a barreira real no banco (Row Level Security) — não apenas na interface
- **Testes em camadas** — unidade, ponta a ponta e regras do próprio banco
- **CI a cada mudança**: tipos, lint, testes e build
- **Deploy automatizado** com ambientes separados de desenvolvimento e produção
- **Segredos fora do código** e revisão contínua de dependências vulneráveis
- **LGPD desde o início**: exportação de dados do titular, exclusão de conta e política de retenção
